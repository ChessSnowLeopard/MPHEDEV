# 🧠 同态加密神经网络后向传播算法

## 算法概述

本文档详细描述了在同态加密环境下，基于分段打包策略的神经网络后向传播算法。该算法结合了高效的密文打包技术和对数级段内聚合优化，实现了在保护数据隐私的前提下进行高效的梯度计算和权重更新。

## 📊 参数定义

### 基本参数
- **$X_m[j]$**：第m个样本的第j个特征
- **$t$**：特征维度数
- **$n$**：样本数量（图像数）
- **$W_{t' \times t}$**：权重矩阵，$t'$表示当前层神经元数量，$t$表示上一层神经元数量
- **$s$**：密文slot数量
- **$k$**：每个密文中打包的特征数量
- **$s/k$**：每个密文中的样本数量（batch size）

### 网络结构参数
- **$t'$**：隐藏层神经元数量
- **$t''$**：输出层神经元数量（分类类别数）
- **$Z_m^j$**：第m个样本在第j个神经元的加权输入（激活前）
- **$A_m^j$**：第m个样本在第j个神经元的激活输出
- **$O_m^j$**：第m个样本在第j个输出神经元的输出
- **$p_m^j$**：第m个样本属于第j个类别的概率
- **$y_m^j$**：第m个样本的真实标签（one-hot编码）

## 🔄 后向传播核心算法

### 1. 输出层梯度计算

#### 1.1 梯度公式推导

由于使用交叉熵损失函数和Softmax激活函数，第m个样本在第j个输出神经元的梯度为：

$$\delta_m^j = \frac{\partial L_m}{\partial O_m^j} = p_m^j - y_m^j$$

其中：
- $L_m = -\sum_{i=0}^{t''-1} y_m^i \log(p_m^i)$ 是第m个样本的交叉熵损失
- $p_m^j = \frac{e^{O_m^j}}{\sum_{i=0}^{t''-1} e^{O_m^i}}$ 是Softmax概率

#### 1.2 密文状态下的梯度计算

在密文状态下，第j个输出类别的梯度密文为：

$$\Delta^j = P^j - Y^j$$

展开形式：
$$\Delta^j = [\delta_0^j, \delta_1^j, \ldots, \delta_{s/k-1}^j | \delta_0^j, \delta_1^j, \ldots, \delta_{s/k-1}^j | \ldots]$$

其中每个分段都包含相同的梯度值，这是由于前向传播中的打包策略导致的。

### 2. 输出层权重梯度计算

#### 2.1 权重梯度公式

对于连接隐藏层第l个神经元到输出层第j个神经元的权重$W_{j,l}$，其梯度为：

$$\frac{\partial \bar{L}}{\partial W_{j,l}} = \frac{1}{s/k} \sum_{m=0}^{s/k-1} \delta_m^j \cdot A_m^l$$

其中$\bar{L} = \frac{1}{s/k}\sum_{m=0}^{s/k-1} L_m$是平均损失。

#### 2.2 密文状态下的权重梯度计算

**步骤1：计算单样本梯度**

计算前k列权重的梯度：
$$G_{j,{0:k-1}} = \Delta^j \odot A_{0:k-1}$$

展开为：
$$G_{j,{0:k-1}} = [\delta_0^j A_0^0, \delta_1^j A_1^0, \ldots, \delta_{s/k-1}^j A_{s/k-1}^0 | \delta_0^j A_0^1, \delta_1^j A_1^1, \ldots, \delta_{s/k-1}^j A_{s/k-1}^1 | \ldots | \delta_0^j A_0^{k-1}, \delta_1^j A_1^{k-1}, \ldots, \delta_{s/k-1}^j A_{s/k-1}^{k-1}]$$

**步骤2：段内聚合求和**

使用对数级段内聚合算法对每个段进行求和：
$$S_{j,{0:k-1}} = \text{LogarithmicSegmentAggregation}(G_{j,{0:k-1}})$$

结果形式：
$$S_{j,{0:k-1}} = [\sum_{m=0}^{s/k-1}\delta_m^j A_m^0, \sum_{m=0}^{s/k-1}\delta_m^j A_m^0, \ldots | \sum_{m=0}^{s/k-1}\delta_m^j A_m^1, \sum_{m=0}^{s/k-1}\delta_m^j A_m^1, \ldots | \ldots]$$

**步骤3：计算最终梯度**

$$\nabla W_{j,{0:k-1}} = \frac{1}{s/k} \cdot S_{j,{0:k-1}}$$

同理可得其他权重块的梯度：$\nabla W_{j,{k:2k-1}}, \nabla W_{j,{2k:3k-1}}, \ldots, \nabla W_{j,{t'-k:t'-1}}$

### 3. 隐藏层梯度计算

#### 3.1 梯度公式推导

对于隐藏层第l个神经元，第m个样本的梯度为：

$$\delta_{hidden,m}^l = \phi'(Z_m^l) \cdot \sum_{j=0}^{t''-1} \delta_m^j \cdot W_{j,l}$$

其中：
- $\phi'(Z_m^l)$ 是激活函数在$Z_m^l$处的导数
- $\delta_m^j$ 是输出层第j个神经元的梯度
- $W_{j,l}$ 是连接隐藏层第l个神经元到输出层第j个神经元的权重

#### 3.2 密文状态下的隐藏层梯度计算

**步骤1：计算加权梯度**

对于隐藏层前k个神经元，计算各输出神经元的加权梯度：

$$R_{j,{0:k-1}} = [\delta_0^j W_{j,0}, \delta_1^j W_{j,0}, \ldots, \delta_{s/k-1}^j W_{j,0} | \delta_0^j W_{j,1}, \delta_1^j W_{j,1}, \ldots, \delta_{s/k-1}^j W_{j,1} | \ldots | \delta_0^j W_{j,k-1}, \delta_1^j W_{j,k-1}, \ldots, \delta_{s/k-1}^j W_{j,k-1}]$$

**步骤2：聚合所有输出神经元的贡献**

$$\Gamma_{backward,{0:k-1}} = \bigoplus_{j=0}^{t''-1} R_{j,{0:k-1}}$$

结果为：
$$\Gamma_{backward,{0:k-1}} = [\sum_{j=0}^{t''-1}\delta_0^j W_{j,0}, \sum_{j=0}^{t''-1}\delta_1^j W_{j,0}, \ldots, \sum_{j=0}^{t''-1}\delta_{s/k-1}^j W_{j,0} | \ldots]$$

**步骤3：乘以激活函数导数**

$$\Gamma_{hidden,{0:k-1}} = \Gamma_{backward,{0:k-1}} \odot \Phi'_{0:k-1}$$

其中：
$$\Phi'_{0:k-1} = [\phi'(Z_0^0), \phi'(Z_1^0), \ldots, \phi'(Z_{s/k-1}^0) | \phi'(Z_0^1), \phi'(Z_1^1), \ldots, \phi'(Z_{s/k-1}^1) | \ldots | \phi'(Z_0^{k-1}), \phi'(Z_1^{k-1}), \ldots, \phi'(Z_{s/k-1}^{k-1})]$$

### 4. 隐藏层权重梯度计算

#### 4.1 权重梯度公式

对于连接输入第f个特征到隐藏层第i个神经元的权重$W_{i,f}$，其梯度为：

$$\frac{\partial \bar{L}}{\partial W_{i,f}} = \frac{1}{s/k} \sum_{m=0}^{s/k-1} \delta_{hidden,m}^i \cdot X_m[f]$$

#### 4.2 密文状态下的权重梯度计算

**步骤1：提取单个神经元梯度**

使用掩码从$\Gamma_{hidden,{0:k-1}}$中提取第i个神经元的梯度：

$$\Gamma_{hidden}^i = [\delta_{hidden,0}^i, \delta_{hidden,1}^i, \ldots, \delta_{hidden,s/k-1}^i | \delta_{hidden,0}^i, \delta_{hidden,1}^i, \ldots, \delta_{hidden,s/k-1}^i | \ldots]$$

**步骤2：计算单样本权重梯度**

与对应的输入特征相乘：

$$G_{i,{0:k-1}} = \Gamma_{hidden}^i \odot X_{0:k-1}$$
$$G_{i,{k:2k-1}} = \Gamma_{hidden}^i \odot X_{k:2k-1}$$
$$\vdots$$
$$G_{i,{t-k:t-1}} = \Gamma_{hidden}^i \odot X_{t-k:t-1}$$

**步骤3：段内聚合求和**

对每个权重块进行段内聚合：

$$S_{i,{0:k-1}} = \text{LogarithmicSegmentAggregation}(G_{i,{0:k-1}})$$

**步骤4：计算最终梯度**

$$\nabla W_{i,{0:k-1}} = \frac{1}{s/k} \cdot S_{i,{0:k-1}}$$

## 🚀 对数级段内聚合优化

### 算法原理

在计算权重梯度时，需要对每个特征段内的$s/k$个样本进行聚合求和。传统的线性聚合方法复杂度为$O(s/k)$，而对数级聚合方法可以将复杂度降低到$O(\log_2(s/k))$。

### 核心思想

使用二进制分解的思想，通过精心设计的掩码模式，实现段内元素的对数级聚合：

1. **第1轮**：相邻元素配对 (距离=1)
2. **第2轮**：每对元素配对 (距离=2)  
3. **第k轮**：前面聚合结果配对 (距离=2^(k-1))

### 算法实现

```python
def logarithmic_segment_aggregation(ciphertext, segment_length):
    """
    对数级段内聚合算法
    
    Args:
        ciphertext: 输入密文
        segment_length: 段长度 (s/k)
    
    Returns:
        聚合后的密文
    """
    result = ciphertext
    rounds = log2(segment_length)
    
    for round_idx in range(rounds):
        step_size = 2 ** round_idx
        
        # 生成当前轮的掩码对
        mask1, mask2 = generate_binary_masks(round_idx, segment_length)
        
        # 第一部分：提取并移位
        L1_pre = result ⊙ mask1
        L1 = rotate_right(L1_pre, step_size)
        
        # 第二部分：直接提取
        L2 = result ⊙ mask2
        
        # 合并结果
        result = L1 ⊕ L2
    
    return result
```

## 🔄 完整后向传播流程

### 算法流程图

```
输入：前向传播结果 P^j, 真实标签 Y^j
│
├─ 1. 计算输出层梯度
│   ├─ Δ^j = P^j - Y^j  (对所有j)
│   └─ 得到输出层梯度密文
│
├─ 2. 计算输出层权重梯度  
│   ├─ G_{j,block} = Δ^j ⊙ A_{block}  (对所有权重块)
│   ├─ S_{j,block} = LogarithmicSegmentAggregation(G_{j,block})
│   └─ ∇W_{j,block} = (1/(s/k)) · S_{j,block}
│
├─ 3. 计算隐藏层梯度
│   ├─ R_{j,block} = Δ^j ⊙ W_{j,block}  (对所有输出神经元j)
│   ├─ Γ_{backward,block} = ⊕_{j} R_{j,block}
│   └─ Γ_{hidden,block} = Γ_{backward,block} ⊙ Φ'_{block}
│
├─ 4. 计算隐藏层权重梯度
│   ├─ 提取单神经元梯度 Γ_{hidden}^i
│   ├─ G_{i,block} = Γ_{hidden}^i ⊙ X_{block}
│   ├─ S_{i,block} = LogarithmicSegmentAggregation(G_{i,block})
│   └─ ∇W_{i,block} = (1/(s/k)) · S_{i,block}
│
└─ 输出：所有层的权重梯度
```

### 伪代码实现

```python
def backward_propagation(P, Y, A_hidden, X, W_output, Z_hidden, batch_size):
    """
    同态加密神经网络后向传播主函数
    
    Args:
        P: 输出层概率密文 [P^0, P^1, ..., P^{t''-1}]
        Y: 真实标签密文 [Y^0, Y^1, ..., Y^{t''-1}]
        A_hidden: 隐藏层激活输出密文
        X: 输入特征密文
        W_output: 输出层权重
        Z_hidden: 隐藏层加权输入密文
        batch_size: 批大小 (s/k)
    
    Returns:
        output_weight_gradients: 输出层权重梯度
        hidden_weight_gradients: 隐藏层权重梯度
    """
    
    # 1. 计算输出层梯度
    output_gradients = []
    for j in range(num_output_classes):
        delta_j = subtract_ciphertext(P[j], Y[j])
        output_gradients.append(delta_j)
    
    # 2. 计算输出层权重梯度
    output_weight_gradients = []
    for j in range(num_output_classes):
        weight_grads_j = []
        for block_idx in range(num_hidden_blocks):
            # 计算单样本梯度
            G = multiply_ciphertext(output_gradients[j], A_hidden[block_idx])
            
            # 段内聚合求和
            S = logarithmic_segment_aggregation(G, batch_size)
            
            # 计算最终梯度
            weight_grad = multiply_plaintext(S, 1.0 / batch_size)
            weight_grads_j.append(weight_grad)
        
        output_weight_gradients.append(weight_grads_j)
    
    # 3. 计算隐藏层梯度
    hidden_gradients = []
    for block_idx in range(num_hidden_blocks):
        # 聚合所有输出神经元的贡献
        gamma_backward = zero_ciphertext()
        for j in range(num_output_classes):
            R = multiply_ciphertext(output_gradients[j], W_output[j][block_idx])
            gamma_backward = add_ciphertext(gamma_backward, R)
        
        # 乘以激活函数导数
        phi_prime = compute_activation_derivative(Z_hidden[block_idx])
        gamma_hidden = multiply_ciphertext(gamma_backward, phi_prime)
        hidden_gradients.append(gamma_hidden)
    
    # 4. 计算隐藏层权重梯度
    hidden_weight_gradients = []
    for i in range(num_hidden_neurons):
        weight_grads_i = []
        
        # 提取第i个神经元的梯度
        gamma_i = extract_neuron_gradient(hidden_gradients, i)
        
        for block_idx in range(num_input_blocks):
            # 计算单样本梯度
            G = multiply_ciphertext(gamma_i, X[block_idx])
            
            # 段内聚合求和
            S = logarithmic_segment_aggregation(G, batch_size)
            
            # 计算最终梯度
            weight_grad = multiply_plaintext(S, 1.0 / batch_size)
            weight_grads_i.append(weight_grad)
        
        hidden_weight_gradients.append(weight_grads_i)
    
    return output_weight_gradients, hidden_weight_gradients
```

## 🔒 安全性与隐私保护

### 数据隐私保护

1. **全程加密**：整个后向传播过程中，所有数据都保持加密状态
2. **梯度隐私**：计算得到的梯度也是加密的，不会泄露训练数据信息
3. **中间结果保护**：所有中间计算结果都在密文域中进行

### 计算安全性

1. **段边界保护**：对数级聚合算法确保不会发生跨段数据泄露
2. **掩码安全**：使用的掩码模式不会泄露数据分布信息
3. **操作原子性**：每个密文操作都是原子的，不会产生部分信息泄露

### 通信安全

1. **密文传输**：所有参与方之间传输的都是密文数据
2. **协议安全**：使用安全的多方计算协议进行密文操作
3. **认证机制**：确保参与方身份的合法性

## 📊 复杂度分析

### 时间复杂度

**传统方法**：
- 输出层权重梯度：$O(t'' \times t' \times s/k)$
- 隐藏层梯度：$O(t' \times t'' \times s/k)$  
- 隐藏层权重梯度：$O(t' \times t \times s/k)$
- **总复杂度**：$O((t'' \times t' + t' \times t) \times s/k)$

**优化方法**：
- 段内聚合：$O(\log_2(s/k))$ 替代 $O(s/k)$
- **总复杂度**：$O((t'' \times t' + t' \times t) \times \log_2(s/k))$

### 空间复杂度

- **掩码存储**：$O(\log_2(s/k))$ 个掩码对
- **中间结果**：$O(t' + t'')$ 个密文
- **梯度存储**：$O(t' \times t + t'' \times t')$ 个梯度密文

### 通信复杂度

- **密文传输**：每轮需要传输 $O(t' + t'')$ 个密文
- **同步开销**：$O(\log_2(s/k))$ 轮同步操作
- **总通信量**：$O((t' + t'') \times \log_2(s/k))$
