```json
  "image_features": 784   // 图像特征总数
}
```

### **2. 数据打包模式**

#### **输入层数据打包**
- **格式**: 特征交错打包
- **模式**: `[feature_0_sample_0, feature_0_sample_1, ..., feature_1_sample_0, feature_1_sample_1, ...]`
- **输出**: `map[uint64]*rlwe.Ciphertext` (7个密文向量)

#### **隐藏层数据重组**
- **方法**: 掩码重组 (mask-based reorganization)
- **输入**: 神经元输出 `[]*rlwe.Ciphertext`
- **输出**: 重组后的向量 `[]*rlwe.Ciphertext`
- **计算步骤**:
  1. 权重打包：将权重矩阵按神经元和特征维度打包
  2. 密文乘法：输入向量与打包权重相乘
  3. 旋转累加：使用log2(k)次旋转实现特征累加
  4. 偏置添加：添加偏置项到结果
  5. 激活函数：应用ReLU激活函数
  6. 输出重组：使用掩码重组输出格式

#### **输出层数据处理**
- **输入**: 重组后的密文向量
- **输出**: 
  - 原始logits: `[]*rlwe.Ciphertext`
  - Softmax概率: `[]*rlwe.Ciphertext`
  - 批次平均损失: `*rlwe.Ciphertext`

### **3. 数据流特点**

#### **层间传递模式**
```
输入层 → 隐藏层: 直接传递 (map[uint64]*rlwe.Ciphertext)
隐藏层 → 输出层: 重组传递 ([]*rlwe.Ciphertext)
输出层 → 损失: 概率分布传递
```

#### **重组机制**
- **掩码重组**: 使用段基掩码提取神经元段，然后重新组合
- **向量数量**: 隐藏层128个神经元重组为1个向量（因为128 < k=128）
- **效率优化**: 标签按类别打包加密，效率提升38倍

## 🏗️ **MPHEDev设计方案**

### **1. 通信数据结构**

#### **系统配置结构**
```go
type SystemConfig struct {
    Slots          int // CKKS槽数
    BatchSize      int // 批次大小
    K              int // 每图像特征数
    N              int // 每向量图像数
    NumVectors     int // 向量总数
    ImageFeatures  int // 图像特征总数
    HiddenSize     int // 隐藏层大小
    OutputSize     int // 输出层大小
}
```

#### **输入层数据结构**
```go
type InputLayerData struct {
    EncryptedVectors map[uint64]*rlwe.Ciphertext // 加密后的向量
    BatchIndex       int                         // 批次索引
    NumVectors       int                         // 向量数量
    VectorSize       int                         // 向量大小
    Metadata         InputLayerMetadata          // 元数据
}
```

#### **隐藏层数据结构**
```go
type HiddenLayerData struct {
    ReorganizedVectors []*rlwe.Ciphertext    // 重组后的密文向量
    NumNeurons         int                   // 神经元数量
    NumOutputVectors   int                   // 输出向量数
    ActivationType     string                // 激活函数类型
    Metadata           HiddenLayerMetadata   // 元数据
}
```

#### **输出层数据结构**
```go
type OutputLayerData struct {
    Logits           []*rlwe.Ciphertext    // 原始logits
    SoftmaxOutputs   []*rlwe.Ciphertext    // softmax后的概率
    Loss             *rlwe.Ciphertext      // 批次平均损失
    NumClasses       int                   // 类别数量
    Metadata         OutputLayerMetadata   // 元数据
}
```

### **2. 层间通信消息**

#### **消息结构**
```go
type LayerMessage struct {
    MessageType   string      // 消息类型
    SourceLayer   string      // 源层
    TargetLayer   string      // 目标层
    BatchIndex    int         // 批次索引
    Data          interface{} // 数据内容
    Metadata      MessageMetadata // 消息元数据
}
```

#### **消息类型**
- `input_to_hidden`: 输入层到隐藏层
- `hidden_to_output`: 隐藏层到输出层
- `output_to_loss`: 输出层到损失计算
- `loss_result`: 损失计算结果

### **3. 数据流管理器**

#### **核心功能**
- **批次管理**: 开始、完成批次处理
- **层状态管理**: 跟踪各层处理状态
- **消息队列**: 管理层间消息传递
- **错误处理**: 统一错误处理机制
- **状态查询**: 提供状态查询接口

#### **协调方法**
- `CoordinateInputToHidden()`: 协调输入层到隐藏层的数据流
- `CoordinateHiddenToOutput()`: 协调隐藏层到输出层的数据流
- `CoordinateOutputToLoss()`: 协调输出层到损失计算的数据流

## 📊 **关键发现**

### **1. 数据格式转换**
- **输入层**: 原始图像 → 特征交错打包 → 密文向量
- **隐藏层**: 密文向量 → 神经元计算 → 掩码重组
- **输出层**: 重组向量 → logits → softmax → 损失

### **2. 效率优化点**
- **标签打包**: 按类别打包，效率提升38倍
- **掩码重组**: 避免复杂的向量操作
- **批次处理**: 充分利用CKKS slot并行计算

### **3. 通信模式**
- **直接传递**: 输入层到隐藏层
- **重组传递**: 隐藏层到输出层
- **聚合传递**: 输出层到损失计算
